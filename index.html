STORAGE CONFIGURATION

Data connection

Connect a Supabase project to persist records in its safety_events table. Without a connection, this prototype uses browser-local demo data.

Quick setupRun supabase/schema.sql in the Supabase SQL Editor, then paste the Project URL and anon key from Project Settings → API.

The anon key is designed for browser use. This prototype stores it in this browser only; never paste a service-role key here.
